PC diZplay is a personal embedded project that puts real-time PC hardware data — GPU temperature, GPU load, GPU fan speed, CPU temperature, CPU load, and RAM usage — onto a tiny 0.96" ST7735 TFT display driven by a Wemos D1 Mini (ESP8266). Navigation between screens is entirely touchless: swipe your hand in front of the APDS-9960 gesture sensor to cycle through metrics. Initial setup takes place through a captive-portal Wi-Fi configuration page served by the device itself.

## How it works

PC diZplay reads hardware sensor values from [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)'s built-in HTTP server (`/data.json`) over your local network. The ESP8266 parses the JSON, extracts the relevant metric for the currently selected screen, and renders it on the TFT display.

<Steps>
  <Step title="Install LibreHardwareMonitor on your PC">
    Start LibreHardwareMonitor and enable its built-in web server so the ESP8266 can poll `http://<PC-IP>:8085/data.json`.
  </Step>
  <Step title="Flash the firmware">
    Open the project in PlatformIO, configure `platformio.ini` for the Wemos D1 Mini, and upload the firmware plus the SPIFFS filesystem image.
  </Step>
  <Step title="Configure Wi-Fi via the captive portal">
    On first boot the device launches a Wi-Fi access point named **Pc diZplay**. Connect to it, fill in your Wi-Fi SSID, password, and LibreHardwareMonitor IP:port, then submit.
  </Step>
  <Step title="Start monitoring">
    The device reboots, connects to your network, and begins polling. Swipe over the APDS-9960 to switch between GPU, CPU, RAM, and clock screens.
  </Step>
</Steps>
